# ДокРевью

Локальное desktop-приложение для проверки Markdown/Diplodoc-документации.

## Безопасность

Проверяемый проект используется строго в режиме **read-only**. Reviewer не создает, не изменяет, не переименовывает и не удаляет файлы или каталоги внутри выбранного проекта. Все правила и настройки хранятся внутри самого Reviewer.

## Возможности v0.3

- выбор любого локального проекта;
- автоматическое предложение `docs/ru`, если такой каталог существует;
- выбор другой папки документации внутри проекта, например `documentation/manual`;
- запрет анализа папки за пределами выбранного проекта;
- битая локальная ссылка;
- несуществующий якорь;
- дублирующийся явный якорь;
- пустая ссылка;
- нежелательная формулировка;
- список без вводного текста;
- пропущенный уровень заголовка;
- повтор слова;
- категории замечаний: Структура, Стиль, Терминология, Markdown, Ссылки;
- фильтрация по уровню и категории;
- пастельная цветовая кодировка: розовый — ошибка, голубой — предупреждение, салатовый — информация.

Выбранная папка документации пока не сохраняется между запусками приложения.

## Запуск

```powershell
npm install
npm run reviewer:dev
```

## Тесты

```powershell
npm run reviewer:test
```

## Production-сборка

```powershell
npm run reviewer:build
```
