# Вкладки «Словарь терминов» и «Правила проверки»

Добавлены две справочные вкладки в главное окно ДокРевью.

- Словарь терминов: поиск по названию, определению и вариантам; фильтр по типу; карточки терминов.
- Правила проверки: краткий справочник направлений проверки.
- Справочник работает без выбранного проекта и не записывает данные в проверяемую папку.

**Ограничение первой версии:** словарь пока только справочный. Записи в `src/renderer/src/data/terminology.ts` не подключены к движку проверки орфографии/терминологии. Добавление и согласование терминов через интерфейс пока не реализовано. Раздел правил содержит обзор направлений, а не исчерпывающий перечень ID всех активных правил.

Для проверки: `npm run reviewer:test` и `npm run reviewer:build`, затем `npm run reviewer:dev`.
